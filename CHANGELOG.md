# Changelog

## 0.1.0

First release.

- `mini-orm-pool`: bounded fair JDBC pool with validation, housekeeping, leak detection, broken-connection eviction, metrics.
- `mini-orm-core`: annotation mapping, sessions with snapshot dirty checking, batching, optimistic and pessimistic locking, lazy proxies, fetch plans, type-safe queries, repositories with derived finders, schema generation and validation, H2 and PostgreSQL dialects.
- `mini-orm-examples`: blog example with a metrics and SQL log page.
